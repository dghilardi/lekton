# Public project website

Mode: Persuade, with concrete technical explanations. Audience: developers and platform teams evaluating and trying Lekton. English and Italian. Primary action: run locally. Evidence: repository capabilities, actual configuration requirements and CLI examples.

Approved compositions: `.impeccable/mocks/minimal-light.png` and `.impeccable/mocks/minimal-dark.png`. User approved both on 2026-10-03: “Ok, procedi”. The earlier blue proposals were rejected.

## Direction contract

THESIS: A public entrance to the same documentation product. A restrained opening explains repository synchronization next to a readable portal preview; practical capability and setup details follow.

OWN-WORLD: Inherit Plus Jakarta Sans, Fira Code for code, amber actions, stacked outline logo, warm light and blue-slate dark surfaces from `style/tailwind.css`. Thin separators, compact controls, small corners. Share tokens through build-time extraction.

STORY: Understand what content the portal hosts, how CI publishes it, what access controls apply, and what is needed to run the application. Optional search and RAG stay explicit. End with runnable commands and source documentation.

FIRST VIEWPORT: A slim header, a roughly equal split between a 42–46px regular-width heading on the left and a flat portal interface on the right; two small actions below the copy. A quiet horizontal repository→sync→portal sequence leads into two practical columns.

FORM: User-pinned minimal extension of the existing default theme; replaces direction seed b15f47a1. Both approved compositions are spatial references. Portal preview is explicitly illustrative until real screenshots are available. It is semantic UI, not a painted plate.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Signature interaction: theme switching updates the entire landing and embedded portal together; the workflow's expandable steps expose actual CLI usage. Preserve reduced-motion support and keyboard navigation. Static locale URLs work without JavaScript. No application behavior changes.
