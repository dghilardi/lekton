## Implementation decisions

Search now uses native `dialog.showModal()` for browser-provided background
inertness, Escape and focus restoration. A single input handler owns result
navigation. The dialog fits the dynamic viewport, scrolls results internally,
provides a close button, uses the existing palette and announces result counts.
The drawer uses an explicit open signal, a button and named navigation. Background
header/content become inert while it is open; route changes and resizing close it.
The skip link explicitly focuses the main landmark because router interception
made the native fragment link unreliable in a regression test.

Anonymous readers without visible documents receive a sign-in action instead of
a duplicate registry destination. Registry empty states distinguish readers and
administrators. Theme accessible names describe both current state and next action.

The source detector reports incumbent font, blockquote border, and scale warnings.
The font is pinned in DESIGN.md; changing it would violate this brief. These
warnings do not establish defects and were not used to justify a redesign.

Early automated runs during asset generation hit mismatched frontend/server
assets and are not counted as verification. Final results below must come from
a completed build with the matching server restarted.

## Independent final review and corrections

Claude Opus 5.5 high verified the implemented search, drawer, skip link, labels,
empty registry and responsive dialog in his own tab. He withheld approval for a
new home loading-state regression: deriving button text from the fallback URL
briefly told signed-in users to log in. The correction exposes successful auth
bootstrap resolution to the home page, keeps a neutral disabled Get Started
until auth/navigation are resolved, and provides a profile action for signed-in
readers with neither docs nor registry. Added raw-SSR and signed-in regression
checks. The review also identified an incumbent search issue within scope:
keyboard selection could leave the result viewport. Active options now scroll
into view; a 12-result narrow-viewport regression checks result 9's geometry.

chunked request bodies. The proxy was corrected outside the repository. Both
real documents and attachment search now return HTTP 200; the local admin query

useful for deterministic keyboard geometry and error handling. No shared search
configuration or index data was changed.

review as approval of that state. His small findings were corrected by the sole
implementer and verified through targeted regression tests and browser checks.
